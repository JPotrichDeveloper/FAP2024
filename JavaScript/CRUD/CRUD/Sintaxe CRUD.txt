O código que você compartilhou é um exemplo completo de um servidor Express com integração com um banco de dados MySQL. Ele permite criar, ler, atualizar e deletar registros de usuários no banco de dados. Vou detalhar o funcionamento da rota DELETE e de todo o código.

Explicação do Código:
1. Importação de Dependências:
express: Framework para criação do servidor e rotas HTTP.
morgan: Middleware para logging das requisições HTTP.
mysql2: Módulo para conexão com banco de dados MySQL.
cors: Middleware para habilitar Cross-Origin Resource Sharing (CORS).
app: Instância do servidor Express.
2. Configuração do MySQL:
A configuração do MySQL é importada de um arquivo mysql_config.js. Certifique-se de que este arquivo contém as configurações corretas para se conectar ao seu banco de dados.
3. Disponibilidade da API:
A API pode ser ativada ou desativada globalmente usando a variável disponibilidade. Se false, todas as requisições retornam a mensagem "Api indisponível".
4. Middlewares Globais:
morgan: Loga detalhes da requisição como método, URL e status.
cors: Habilita CORS, permitindo que a API seja acessada por diferentes domínios.
express.json() e express.urlencoded({extended:true}): Fazem o parsing do corpo das requisições como JSON e URL-encoded.
5. Conexão com o Banco de Dados:
A conexão com o banco de dados é estabelecida usando as configurações definidas no mysql_config.
6. Rotas da API:
GET /: Retorna "Olá mundo" para verificar se a API está funcionando.
POST /usuario/cadastro: Insere um novo usuário no banco de dados.
GET /usuario/busca: Retorna todos os usuários cadastrados no banco de dados.
GET /usuario/busca/:id_usuario: Retorna um usuário específico pelo id_usuario.
PUT /usuario/atualizar/:id_usuario: Atualiza os dados de um usuário específico.
DELETE /usuario/deletar/:id_usuario: Deleta um usuário específico pelo id_usuario.
7. Rota DELETE (Deletar Usuário):
app.delete("/usuario/deletar/:id_usuario", (req,res)=> {...}):
Captura o id_usuario da URL.
Executa a query SQL DELETE FROM usuarios WHERE id_usuario = ?.
Verifica se o id_usuario foi encontrado e retorna uma mensagem apropriada.
Se ocorrer um erro, uma mensagem de erro com o status 500 é enviada.
Testando a Rota DELETE com Thunder Client, Postman ou cURL
Você pode testar a rota DELETE como segue:

Usando cURL:

bash
Copiar código

Usando Thunder Client ou Postman:

Selecione o método DELETE.
Use a URL http://localhost:3000/usuario/deletar/1 (substitua 1 pelo ID do usuário que deseja deletar).
Envie a requisição e verifique a resposta.
Iniciando o Servidor
app.listen(3000,()=>{...}): Inicia o servidor na porta 3000. Após iniciar o servidor, você verá a mensagem "Servidor iniciado na porta 3000" no console.
Esse código fornece uma base robusta para criar, ler, atualizar e deletar dados em um banco de dados MySQL usando Express e Node.js.
